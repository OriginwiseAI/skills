# Decision-Point Storyboard

**Use this worksheet when a process includes a normal route, evidence checks, and a stop or escalation branch.**

| Scene | What the viewer sees | Narration or label | Decision | Evidence / source reference | Next owner |
| --- | --- | --- | --- | --- | --- |
| 1. Trigger | The cue, role, and scope |  | What makes this process relevant? |  |  |
| 2. First safe check | A status, item, location, or record |  | Is it safe to proceed? |  |  |
| 3. Normal path | The expected next action |  | What result keeps work on the normal path? |  |  |
| 4. Evidence | A value, label, screenshot, part, or form |  | What must be captured? |  |  |
| 5. Stop condition | The threshold or condition that changes the action |  | When should the viewer pause? |  |  |
| 6. Escalation | Handoff package and responsible role |  | Who decides next? |  |  |
| 7. Confirmation | Final check and link to the current source |  | How does the viewer know the task is complete? |  |  |

## Design checks

- [ ] The trigger is specific enough for the intended role.
- [ ] The normal path and exception path are both visible.
- [ ] The stop condition appears before an irreversible action.
- [ ] Every chart, screenshot, diagram, or label helps the viewer make a decision.
- [ ] The viewer can identify the next owner and the canonical source.
- [ ] Sensitive details are retained in the appropriate controlled system.
